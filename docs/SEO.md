# SEO، AEO و GEO دبی خرید

## هدف و موجودیت اصلی

- نام رسمی: `دبی خرید`
- نام لاتین مکمل: `DubaiKharid`
- دامنه canonical: `https://dubaykharid.ir`
- تعریف موجودیت: سرویس فارسی‌زبان مستقل برای ثبت درخواست خرید از فروشگاه‌های دبی/امارات، برآورد هزینه و هماهنگی ارسال کالا به ایران.
- دبی خرید وابسته، مالک یا نماینده Amazon، Noon، Nike، Adidas، Shein و سایر فروشگاه‌ها یا برندهای مبدأ نیست.

## نقشه canonical کلیدواژه به صفحه

| صفحه | هدف اصلی |
|---|---|
| `/` | برند دبی خرید و معرفی عمومی خدمات خرید از امارات |
| `/buy-from-dubai` | خرید مستقیم از دبی |
| `/stores/amazon` | خرید از آمازون امارات |
| `/stores/noon` | خرید از نون دبی |
| `/stores/namshi` | خرید از نمشی امارات |
| `/brands/[slug]` | خرید محصولات همان برند از دبی |
| `/stock-laptops` | خرید لپ‌تاپ استوک موجود |
| `/product/[id]` | نام و مشخصات همان کالای واقعی |

صفحه `/buy-from-dubai` مرجع اصلی عبارت «خرید مستقیم از دبی» است. صفحه اصلی از این موضوع پشتیبانی می‌کند و با anchor توصیفی به صفحه مرجع لینک می‌دهد تا cannibalization ایجاد نشود.

## Metadata و canonical

- Metadata پایه و title template در root layout قرار دارد.
- صفحات فروشگاه، برند و محصول metadata داینامیک و canonical مستقل دارند.
- URLهای فیلتر و مرتب‌سازی صفحات دسته‌بندی به canonical بدون query اشاره می‌کنند.
- صفحات فاقد محتوای محصول کافی noindex هستند تا thin content ایندکس نشود.

## Sitemap

`/sitemap.xml` شامل صفحه اصلی، راهنمای خرید از دبی، درباره ما، فهرست برندها، لپ‌تاپ استوک، فروشگاه‌های واقعی DB، برندهای دارای محصول فعال، محصولات فعال و لپ‌تاپ‌های AVAILABLE است.

- محصولات و لپ‌تاپ‌ها با `updatedAt` واقعی منتشر می‌شوند.
- لپ‌تاپ SOLD/INACTIVE، محصول غیرفعال، صفحات خصوصی، API و نتایج جستجو حذف شده‌اند.
- queryها فقط فیلدهای لازم را select می‌کنند.

## Structured Data

- `Organization` و `WebSite` در root layout
- `AboutPage` در صفحه درباره ما
- `FAQPage` فقط برای FAQ قابل‌مشاهده در `/buy-from-dubai`
- `BreadcrumbList` در landing، فروشگاه، برند و محصول
- `Product` برای محصولات واقعی
- `Offer` فقط برای لپ‌تاپ AVAILABLE دارای قیمت واقعی؛ قیمت تومان برای currency استاندارد `IRR` به ریال تبدیل می‌شود.
- برای محصولات خارجی/کاتالوگی که مبلغ نهایی نیازمند بررسی است Offer ساختگی تولید نمی‌شود.
- Review و AggregateRating تولید نمی‌شوند.

JSON-LD از helper مشترک استفاده می‌کند و `<` را escape می‌کند تا داده DB نتواند script را بشکند.

## Noindex

صفحات زیر `noindex, follow` هستند:

- cart، wishlist، login، payment، tracking، search و profile
- admin و زیرصفحه‌های آن
- دسته‌بندی‌های client-only فعلی تا زمان اتصال listing آن‌ها به DB
- برندهایی که هیچ محصول فعال ندارند

robots.txt مسیرهای `/admin/`، `/api/`، `/profile/` و `/payment` را از crawl خارج می‌کند و sitemap را معرفی می‌کند.

## 404 و موجودی

- فروشگاه و برند ناشناخته با `notFound()` پاسخ واقعی 404 می‌دهند.
- شناسه‌های دیتابیسی ناشناخته محصول پاسخ 404 می‌دهند.
- لپ‌تاپ SOLD/INACTIVE در sitemap قرار نمی‌گیرد و صفحه عمومی آن 404 است؛ InStock برای آن منتشر نمی‌شود.
- محصولات فعال کاتالوگ حتی بدون Offer می‌توانند صفحه توضیحی داشته باشند؛ قیمت نهایی از مرورگر پذیرفته نمی‌شود.

## بدهی محتوایی

- صفحات شرایط استفاده، حریم خصوصی، لغو/مرجوعی باید پس از تأیید متن حقوقی واقعی کسب‌وکار ایجاد شوند.
- صفحات دسته‌بندی پس از اتصال listing به PostgreSQL می‌توانند از noindex خارج و وارد sitemap شوند.
- تصاویر مهم باقی‌مانده می‌توانند پس از تعریف policy دامنه‌های remote به `next/image` منتقل شوند.
